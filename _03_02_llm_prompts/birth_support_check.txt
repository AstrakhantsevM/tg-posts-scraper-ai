Тебе предоставлены данные (тексты постов) по одному из регионов.

Определи, есть ли в переданном тексте реальная фактическая информация про:
- меры поддержки семей с детьми (льготы, выплаты, субсидии)
- законы о запрете склонения к аборту
- сертификаты для молодожёнов на репродуктивное обследование

Верни ответ строго в JSON следующей структуры:

{
  "found": true | false,
  "measures": [
    {
      "type": "краткое название меры",
      "form": "форма предоставления (денежная выплата / сертификат / льгота / закон / ...)",
      "amount": "сумма или null если не указана",
      "conditions": "условия получения",
      "notes": "дополнительные нюансы или null"
    }
  ]
}

Если информации в тексте нет — верни:
{"found": false, "measures": []}

Пример структуры (ЭТО ТОЛЬКО ШАБЛОН, НЕ ИСПОЛЬЗУЙ ЭТИ ДАННЫЕ В ОТВЕТЕ):
{
  "found": true,
  "measures": [
    {
      "type": "НАЗВАНИЕ МЕРЫ (из текста)",
      "form": "ФОРМА (из текста)",
      "amount": "10 000 руб.",
      "conditions": "УСЛОВИЯ (из текста)",
      "notes": "НЮАНСЫ (из текста)"
    }
  ]
}
